YouTube API key (optional)

Everything works without a key: videos, channels, previews and logos. With a key, all of a channel's videos load (not just the latest ~200), and lookups are a little faster and more reliable.

How to get a key (free):
  1. Go to console.cloud.google.com and create a project.
  2. In APIs & Services › Library, enable YouTube Data API v3.
  3. In Credentials › Create credentials, create an API key and paste it here.
  4. Recommended: restrict the key to your own site address (Website restrictions).
